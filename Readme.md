## **Customer Feedback Analytics Dashboard**

##### **Overview**

An interactive Excel dashboard developed to analyze customer feedback, customer satisfaction, dealer performance, and complaint resolution metrics.



#### **Business Objective**

Monitor customer satisfaction and identify key improvement areas through data-driven insights.



#### **Tools Used**

* Microsoft Excel
* Power Query
* Power Pivot
* DAX
* VBA
* Pivot Tables
* Pivot Charts



#### **KPIs**

* Total Feedback
* Average Rating
* CSAT %
* NPS
* Average Resolution Days

#### 

#### **Dashboard Features**

* Dynamic KPI Cards
* Interactive Slicers
* Dynamic Insights Panel
* Dealer Performance Analysis
* Resolution Analysis
* VBA Automation



#### **Skills Demonstrated**

Excel | Power Query | Power Pivot | DAX | VBA | Dashboard Design | Business Analytics
